# Screen recording shot list

Record on the physical iPhone with the latest iOS, from the Home Screen.
Control Center → Screen Recording. Start with the app icon, not from Xcode.

The recording must begin with the app launching. Keep it under about three
minutes; no narration is required, but a calm voice-over describing each step is
fine.

| Time | What to show |
|---|---|
| 0:00 | Home Screen. Tap the **TimeTrackete** icon. |
| 0:05 | Today, right after launch. Point out the date, the state and the target. |
| 0:15 | Tap the large button → "Working since …" and **Leave at** appear. |
| 0:25 | Tap again → break. Tap → back in. Tap → out. The day closes and the balance updates. |
| 0:45 | **History**: week and month balances. Open a day and show the timeline and stamps. |
| 1:05 | Back to Today → **pencil** → remove or retime one stamp → **Save**. Show the corrected day. Mention "Revert to recorded stamps". |
| 1:25 | **Settings**: change weekly hours, toggle a working day, set **Standard lunch** to 60 minutes, show rounding and holidays. |
| 1:50 | Optional: open **Shortcuts**, run the **Stamp** shortcut, return to Today and show the new stamp. This is the action used for Back Tap and Siri. |
| 2:05 | Optional: Settings → **Export taps.log**, or Files → On My iPhone → TimeTrackete, to show that the log is local. |
| 2:15 | End. |

Tips:

- Do not start from a deep link, a notification, or Xcode — Apple asks for the
  app launching normally.
- Show one complete day with four stamps so the toggle is obvious.
- If you demonstrate Back Tap, the double-tap itself is not visible on a screen
  recording; show the Shortcut running and the resulting stamp in the app.
- Do not include personal times or names you would not want a reviewer to see;
  the sample data in the app is fine.
