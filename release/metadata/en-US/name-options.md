# App Store name

`TimeTracker` is already on the App Store (by ExhibitForce), so the store name
must differ. The **home-screen name stays "TimeTracker"** via
`CFBundleDisplayName`; only the App Store listing name changes.

`name.txt` currently proposes **Badge Hours**. App Store Connect reserves the
name when you create the record, so try in this order:

1. `Badge Hours`
2. `Punch Ledger`
3. `Hours Ledger`
4. `Badge Hours: Time Ledger`

Avoid names that ride on another app's name; a distinct name also makes review
smoother.
