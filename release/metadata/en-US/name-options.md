# App Store name

The store name is **TimeTrackete**. `TimeTracker` was already registered by
ExhibitForce, so the listing uses the unique spelling.

The home-screen name matches (`CFBundleDisplayName`), while the bundle ID, the
Xcode project and the repository keep the internal name `TimeTracker` /
`time-tracking`. Those are not user-visible, and changing the bundle ID would
create a new app container and orphan the existing log on the phone.
